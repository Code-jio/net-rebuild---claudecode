# 高端装备制造联合实验室官网改造 设计方案

Date: 2026-05-19 | Status: 已确认

## 1. 背景与目标

### 1.1 项目背景

现有网站 [mer.wuqiwan.cn](https://mer.wuqiwan.cn) 为"智能制造测试验证与评价工业和信息化部重点实验室高端装备制造联合实验室"成员单位线上手册（Vue SPA）。实验室由工信部重点实验室、中国航空学会、宁波市江北区政府三方共建，汇聚 40+ 成员单位、50+ 专家委员、3 家分实验室。

### 1.2 甲方反馈（原文）

> "成员单位线上版手册亮点不够突出，建议把联合实验室的主要业务模块优先展示，各成员单位可设置专属关键词，突出成员单位特色与业务重点，提升手册实用性与展示效果。"

### 1.3 改造目标

| # | 目标 | 对应措施 |
|---|------|----------|
| 1 | 业务模块优先展示 | 首页信息架构重排，产业服务从底���提升至 Hero 下方 |
| 2 | 成员单位设置专属关键词 | 新增技术标签 + 行业标签系统（预设词库） |
| 3 | 突出成员特色与业务重点 | 卡片增加标签 chips，蓝色=技术，金色=行业 |
| 4 | 提升实用性与展示效果 | 首页品牌展示 + 成员检索独立二级页面，视觉全面升级 |

### 1.4 目标用户

对外展示 / 获客：潜在客户、合作伙伴通过平台了解实验室能力和各成员单位专长，寻找合作方。

### 1.5 参考站点

- 天目山实验室 (tmslab.cn) —— 科技感、粒子背景、渐变色彩
- 中国民航大学 (cauc.edu.cn) —— 学术正式、大横幅轮播
- 四川天府新区西工大先进动力研究院 (sichuan.nwpu.edu.cn) —— 研究机构风、规范简洁

## 2. 信息架构

### 2.1 页面结构

```
首页（品牌展示）
├── 1. Hero + 组织架构
│   ├── 实验室全称 + 定位语 + CTA 按钮
│   ├── 右侧形象图
│   └── 底部共建方条
├── 2. 产业服务（9 大模块，3×3 网格）
├── 3. 核心数据（4 项数字统计）
├── 4. 分实验室（3 卡片 + 研究方向标签）
└── 5. 成员单位 CTA → 跳转 /members/

成员检索页 /members/（二级页面）
├── 分类筛选 chips + 关键词标签云（多选叠加，实时过滤）
└── 成员卡片网格 → 点击进详情

成员详情页 /members/:id
├── 关键词标签展示（新增：蓝色技术标签 + 金色行业标签）
├── 信息网格（联系人、电话、邮箱、地址、网址）
├── 图文简介
├── 相关成员推荐（新增：同关键词匹配）
└── 上/下一条导航
```

### 2.2 导航

- 简洁型固定吸顶导航（滚动时毛玻璃效果）
- 链接：首页 / 产业服务 / 成员单位 + CTA 按钮

## 3. 数据模型

### 3.1 关键词系统

**规则**：纯预设词库，管理员统一维护，成员单位从中勾选。

**标签分类**：

| 类型 | 视觉标识 | 示例 | 用途 |
|------|----------|------|------|
| 技术标签 | 蓝色 chips | eVTOL、3D打印、磁性材料、氢燃料电池 | 描述技术能力 |
| 行业标签 | 金色 chips | 航空航天、新能源汽车、医疗器械 | 描述服务行业 |

**数据字段**（member 表新增）：

```
tech_tags: JSON string[]    // ["eVTOL", "3D打印", "磁性材料"]
industry_tags: JSON string[] // ["航空航天", "新能源汽车"]
```

**管理后台**：独立的标签词库 CRUD + 成员标签勾选界面。

### 3.2 API 变更

| 接口 | 变更 | 说明 |
|------|------|------|
| `GET /api/index/members` | 扩展 | 返回增加 tech_tags、industry_tags |
| `GET /api/index/keywords` | 新增 | 返回完整标签词库 + 各标签使用频次 |
| `POST /api/admin/keywords` | 新增 | 管理端标签词库维护 |
| `PUT /api/admin/members/:id/tags` | 新增 | 管理端设置成员标签 |

### 3.3 现有数据（从 API 提取）

- 40+ 成员单位，分 3 类：企业(category_id=16)、研究院(15)、高校(14)
- 9 大产业服务（企业服务联盟、政策赋能、航展展位、趋势分析、测试验证评价、技术资料库、技术交流推广、人才对接、深化合作）
- 3 家分实验室（先进动力系统、先进磁场与装备系���、高效驱动轴智能制造）
- 数据统计：40+ 成员、50+ 专家、3 分实验室、2 团体标准

## 4. 页面设计

### 4.1 设计方向

**Industrial Precision × Academic Authority**（工业精密 × 学术权威）

- 色彩：深海军蓝 + 浅灰白分区交替，蓝色为主色，金色为功能点缀
- 字体：Rajdhani（数字/数据）+ Noto Sans SC（中文标题/正文，300~900 全字重）
- 布局节奏：深色 Hero → 浅色业务 → 深色数据 → 浅色分实验室 → 深色 CTA

### 4.2 色彩体系

| 用途 | 色值 | 说明 |
|------|------|------|
| 背景最深 | `#060d17` | Hero、Footer |
| 背景中深 | `#0f1d32` | 数据区、CTA 区 |
| 主蓝色 | `#2563eb` | 按钮、链接、技术标签 |
| 点缀金 | `#c8943e` | 行业标签、数据后缀 |
| 浅色背景 | `#f8f9fb` | 产业服务、分实验室区域 |
| 白色卡片 | `#ffffff` | 内容卡片 |
| 边框 | `#e2e8f0` | 卡片边框 |

### 4.3 首页各区块

#### 区块 1：Hero + 组织架构

- 深海军蓝全屏背景 + 网点纹理叠加
- 左侧：实验室 badge（国家级产业平台 + 专业学术组织 + 地方政府）、大标题（"高端装备制造联合实验室"，"联合实验室"四字做蓝青渐变）、定位语、双 CTA（"探索业务模块""寻找合作单位"）
- 右侧：形象图（带几何装饰环和金色线条）
- 底部共建方条（毛玻璃效果）：工信部重点实验室 | 中国航空学会 | 宁波市江北区政府

#### 区块 2：产业服务

- 浅灰白背景，深色标题
- 3×3 卡片网格，每卡片：图标（蓝底圆形衬底）+ 标题 + 简短摘要
- Hover：卡片上浮 + 顶部蓝色渐变条展开 + 蓝色边框高亮

#### 区块 3：核心数据

- 中深蓝背景
- 4 数据项横向排列：40+ 成员单位 | 50+ 专家委员 | 3 分实验室 | 2 团体标准
- 数字使用 Rajdhani 字体（64px，白色渐变），后缀使用金色

#### 区块 4：分实验室

- 浅灰白背景
- 3 卡片横向排列，每卡片：图标 + 名称 + 发起单位 + 描述 + 研究方向标签 chips

### 4.4 成员检索页（/members/）

- 分类筛选：企业 / 高校 / 研究院 chips（单选切换，默认"全部"）
- 关键词标签云：技术标签 + 行业标签按频次展示，标签大小反映使用频次，点击多选叠加
- 两个筛选条件实时联合过滤（分类 + 关键词标签交集）
- 结果区：成员卡片网格（auto-fill, min 280px）
- 成员卡片：类别 badge + 名称 + 技术标签(蓝) + 行业标签(金) + 简介(2行截断) + 联系人

### 4.5 成员详情页（/members/:id）

- 顶部：类别标签 + 名称 + 技术标签 + 行业标签（醒目展示）
- 信息网格：联系人、电话、邮箱、地址、网址
- 图文简介
- 相关成员推荐：同关键词匹配，横向卡片
- 底部：上/下一条导航

## 5. 技术范围

### 5.1 改动清单

| 层级 | 内容 | 程度 |
|------|------|------|
| 前端 - 首页 | 完全重写，4 区块品牌展示 | 100% 重写 |
| 前端 - 成员检索页 | 独立二级页面，标签云+筛选+卡片网格 | 新页面 |
| 前端 - 成员详情页 | 增加标签展示 + 相关推荐 | 微调 |
| 前端 - 导航 | 新增全局导航栏 | 新增 |
| 后端 - API | 扩展 members 接口，新增 keywords 接口 | 轻量扩展 |
| 后端 - 管理后台 | 标签词库管理 + 成员标签设置 | 新增 |
| 数据库 | members 表加 tech_tags + industry_tags (JSON) | 扩展 |
| 数据库 | 新建 keywords 表（标签词库） | 新增 |

### 5.2 不涉及

- 不更换技术栈（保留 Vue 3 + Vite）
- 不改变现有 API 契约（仅扩展字段）
- 不改造产业服务和分实验室的后台管理（沿用现有 homeContent 接口）

## 6. 与现有设计的对比

| 维度 | 改造前 | 改造后 |
|------|--------|--------|
| 首页定位 | 成员通讯录 + 附带介绍 | 品牌门户 + 能力展示 |
| 业务模块位置 | 页面中下部，访客需要滚动 | Hero 下方第二区块，首屏可见 |
| 成员差异化 | 仅类别标签（企业/高校/研究院） | 技术标签+行业标签双维度区分 |
| 页面结构 | 单页 | 首页 + 成员检索页 + 详情页 |
| 关键词 | 无 | 预设词库，标签云动态筛选 |
| 成员检索 | 分类 + 关键字搜索 | 分类 + 搜索 + 标签云多选叠加 |
| 视觉节奏 | 单一蓝色背景全程 | 深-浅-深-浅分区交替 |
